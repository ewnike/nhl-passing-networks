# Official IIHF Rink Dimensions

## Source

**IIHF Official Rule Book 2025/26**  
Appendix VI — Infographics  
Page 222 — Rink Lines

All measurements in the source diagram are given in centimeters.

## Purpose

This diagram is the authoritative geometry reference used to derive
metric rink coordinates for the HockeyRink 56-landmark configuration.

Coordinate convention used in this project:

- Origin `(0, 0)`: center-ice face-off spot
- X-axis: rink length
- Y-axis: rink width
- Units: meters

For the 30 m rink configuration:

- Rink length: `60.00 m`
- Rink width: `30.00 m`

Derived landmark coordinates should be documented separately from the
original IIHF source material.
